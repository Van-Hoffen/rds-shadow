05 · Права RDP-Tcp. Редактор прав с галочками: Инфо / Теневой доступ / Сообщение / Завершение (это Query, Remote Control, Message, Logoff). Строки стандартных учёток — только для чтения. Галочки управляют правами через WMI. Требует прав администратора на сервере.

Решено 4.1: В — колонка называется «Теневой доступ». Право Remote Control одно (просмотр+управление, ТЗ §3), поэтому «Теневой доступ» точнее, чем «Управление», и не путается с клиентским режимом управления. Варианты А и Б отклонены.
