Логофф user_iv выполнен

04 · Завершение сеанса. Опасное действие требует ввода имени пользователя без домена и подтверждения; после — уведомление внизу справа. Журнал пишет logoff.requested / ok / fail.

Решено 3.1: А — тост без «Отменить», logoff необратим. Поток: кнопка «Завершить сеанс» → окно с полем и кнопками LogOff / Отмена → ввод имени без домена (отсекается по \) → LogOff → окно закрывается → программа опрашивает список сеансов выбранного узла (интервал 2 с, максимум 40 с), ждёт исчезновения пользователя с этим ID → уведомление «Логофф выполнен» внизу справа, фокус не переходит. Если за 40 с сеанс всё ещё виден — предупреждение, а не успех.
