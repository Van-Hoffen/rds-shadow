# 0006 — Сворачивание в один Windows-крейт, отказ от Linux

- Статус: принято 2026-11-19
- Тип: explanation

## Контекст

Разделение на `rds-shadow-core` (платформо-нейтральное) и `rds-shadow` было мотивировано кроссплатформенным просмотрщиком (`rds-shadow-audit`, Windows + Linux). Linux не используется — теневое подключение только Windows, а просмотрщик на Linux не нужен. Разделение оказалось преждевременной абстракцией и источником путаницы.

## Решение

- Свернуть три крейта в **один Windows-крейт `rds-shadow`**: модули ядра (`config`, `event`, `filter`, `writer`, `command`) перенесены в него, просмотрщик стал bin `src/bin/rds-shadow-audit.rs`.
- Продукт — **Windows-only**: клиент (GUI), CLI и просмотрщик.
- CI — только Windows (`ci.yml` без linux-job).
- Релиз — только Windows (`release.yml` без linux-job и без linux-артефакта).
- Обновлены README, ТЗ §6/§11/§13, STATUS, гайд по релизу, AGENTS.md и скиллы/агенты.

## Почему так

- Linux не используется; поддержка Linux и «нейтральное» ядро — лишняя сложность без потребителя.
- Один крейт проще: нет границы «ядро/не-ядро», нет Windows-only кода в «нейтральном» ядре.
- Тесты ядра (22) переехали в крейт и теперь гоняются только на Windows (CI); локально на Linux — только кросс-проверка компиляции.

## Отклонено

- Оставить кроссплатформенный просмотрщик — не нужен, источник путаницы.
- Оставить отдельное ядро ради тестов на Linux — преждевременная абстракция.

## Остаточный риск

- Тесты больше не гоняются на Linux-машине разработки; проверка — только Windows CI и локальная кросс-компиляция.
- Релиз `v0.3.1` (предыдущий) был собран по трёхкрейтовой схеме; следующая версия будет уже однокрейтовой, Windows-only.
